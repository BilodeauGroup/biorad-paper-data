Figure S6. RMS boundary waviness

rms_waviness.csv contains one Wq value per ligand, in angstroms. Values were
calculated from the plane-detrended, Gaussian-filtered upper boundary on a 0.15
angstrom analysis grid. The cutoff wavelength was 5 angstrom. Figure S5 contains the
corresponding fields on the finer grid used to display maps.
